사용법

  1. 이미지 — 배경이 투명한 PNG를 올려주세요. 배경이 흰색이면 흰 배경 자동 제거를 켜면 됩니다.
  2. 파츠 — 과일·동물·하트·크런치 중에서 골라 담으면 슬라임 안쪽에 박힙니다.
  3. 누르기 — 슬라임을 꾹 누르면 눌린 자국이 생기고 소리가 납니다. 끌면 문지르는 소리가 나요.
  4. 저장 — PNG 한 장 또는 영상(webm)으로 저장해서 그대로 올릴 수 있어요.

모든 처리는 이 브라우저 안에서만 일어납니다. 올린 이미지는 어디로도 전송되지 않아요.
